## งานของ Step 21 — CS คิวรับคืน + ปิดงาน + แบบประเมิน
เป้าหมาย: ปิดวงจรงานลูกค้าได้ครบทั้งกรณีอนุมัติและไม่อนุมัติ

ขอบเขตงาน:
1. หน้า `/cs` แท็บ: พร้อมรับที่สาขา, รอลูกค้าอนุมัติ (บันทึกผลแทนลูกค้าพร้อมเหตุผล), เปิดวันนี้ (ยังรอชำระ)
2. Pickup panel อนุมัติซ่อม: สรุปยอด (หักค่าดำเนินการ), badge สถานะชำระ, ดูใบเสนอราคา, รับชำระ (QR/link/POS), ปิดงาน disabled จนยอดค้าง 0
3. Pickup panel ไม่อนุมัติ: ค่าใช้จ่ายที่ไม่คืน, ปุ่ม Trade-in (ลิงก์ไป `/tradein?type=2&jobId=` — หน้า Trade-in ทำใน Step 22), รับสินค้ากลับอย่างเดียว, ปิดงาน
4. ปิดงาน → LON แบบประเมิน; หน้า public `/s/[token]` ดาว 1–5 + ความคิดเห็น

กติกา:
- ทำเฉพาะขอบเขตของ step นี้ ห้ามทำงานของ step ถัดไปล่วงหน้า
- ถ้าเอกสารไม่ชัดหรือขัดกัน ให้เลือกตามลำดับความจริงใน AGENTS.md และจดคำถามไว้ใน docs/OPEN_QUESTIONS.md
- เมื่อเสร็จ ให้รัน `pnpm lint && pnpm typecheck && pnpm test` จนผ่าน
- ห้าม git commit (ผมจะตรวจแล้ว commit เอง)

เมื่อเสร็จให้สรุป: (1) ไฟล์ที่สร้าง/แก้ (2) วิธีทดสอบด้วยมือทีละข้อ (3) สิ่งที่ยังไม่ได้ทำหรือคำถามค้าง
